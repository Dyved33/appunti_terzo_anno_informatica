Orale riguardo lezioni + libro = Network Security Essentials (William Stallings)  

Prima di fare un'**identificazione** (es con documento identificativo) è necessaria un'**autenticazione** (es username e password)

Voglio sia username e password per dare un'**autorizzazione** perché voglio:
- **Accounting** = verificare chi fa cosa
- Dare ad ogni utente ciò che può vedere

Compito = trovare situazioni in cui si fa autenticazione senza identificazione

Un computer è sicuro $\iff$ è accessibile solo a chi è autorizzato (sicurezza = fa quello che deve fare e lo permette solo a chi può farlo). 

1. Confidenzialità = informazioni lette o accedute solo da chi è autorizzato
2. Integrità = informazioni modificabili solo da chi è autorizzato
3. Disponibilità = informazioni disponibili a chi accede

Un dispositivo non è mai sicuro !!! Basti pensare che un sistema sicuro ieri potrebbe non esserlo domani

Come proteggersi?
- Physical security = accesso fisico di utenti alle macchine
- Operational/procedural security = 
- MANCA

Piano di sicurezza:
- Risk avoidance = necessito di una connessione internet permanente
- Deterrence = pubblicizzare strumenti di difesa e punizione
- Prevention = firewall
- Detection = IDS (intrusion detecting system)
- Reaction = recovery e tribunale

RICORDA:  la sicurezza richiederebbe spesso il ridisegno (non sempre possibile). È una proprietà di vari livelli architetturali.
