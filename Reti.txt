# Reti

standard odierno = tcp/ip
come avviene la comunicazione tra client e server? su reti distinte il protocollo tcp crea un canale vistuale da cliente a server che agistce da "tubo di connessione". 

protocolli internet:
- applicazione: di supporto alle applicazioni di rete: FTP, SMTP, HTTP
- trasporto: trasferimento dei mesasggi a livello di applicazione tra il modulo client e server di un'applicazione: TCP, UDP
- rete: instradamento dei datagrammi dall'origine al desrinatario: IP, MANCA

pacchetto a livello:
- applicazione = messaggio 
- trasporto = segmento
- rete = datagramma
- link = frame

socket = per aprire un canale di comunicazione esiste una primitiva socket. si sfrutta il protocollo tcp con buffer e variabili. 
un processo invia/riceve, messaggi a /da la sua socket MANCA

porte well known = fanno cose specifiche 

protocollo HTTP= protocollo a libello di applicaizione del web. sfrutta un modello client/server in cui il client è il browser che richiede, riceve e visualizza gli oggetti del web. il server invece invia oggetti inrisposta a una richiesta 

ora il protocollo standartd è il HTTPS con S che significa secure

i messaggi HTTP si dividono in richiesta e risposta. la richiesta è in formato ASCII (leggibile all'utente). è composta da riga di richiesta, righe di intestazione e infine un carriage return e un line line feed indicano la fine del messaggio

tipi di metodi:
- GET
- POST
- PUT 
- HEAD (restituisce solo le intestazioni (header) di una risorsa, senza inviare il corpo (il contenuto effettivo) della risorsa stessa)
- DELETE 

il messaggio HTTP di risposta è composto da riga di stato (protocollo codice di stato espressione di stato), righe di intestazione e dati (e.g. il file HTML richiesto) 

N.B. proxy cache = server vicino al client che si salva le informazioni/pagine già richieste per essere più performante la prossima volta che gli viene fatta la stessa richiesta

Ricorda = il cookie sono piccoli file di testo che i siti web salvano sul dispositivo dell'utente (computer, smartphone o tablet) durante la navigazione. Vengono utilizzati dal server del sito per memorizzare informazioni specifiche, come le credenziali di accesso, le preferenze linguistiche o il contenuto del carrello e-commerce, permettendo al sito di riconoscere l'utente nelle visite successive e personalizzare l'esperienza (informazioni cifrate) 

FTP = protocollo usato per il trasferimento di informazioni. non apre un socket per la comunicazione, ma ne apre 2: uno per il trasferimento dei dati e l'altro per mantenere lo stato della sessione.

controllo di qualità = quando viene mandato un messaggio avviene una somma byte per byte ??? se ho mandato un numero di bit dispari aggiungo 1 per avere i bit pari, viceversa aggiungo uno 0 (nel primo caso c'è una perdita di qualche informazione). è un controllo di integrità

SMTP = simple mail transfer protocol. utilizzato per spedire posta. non so cosa dire di specifico. formato del messaggio = simile a HTTP
esiste uno standard chiamato MIME che serve per codificare contenuti diversi dal testo per trasformarli in testo
